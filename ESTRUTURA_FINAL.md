## COMO USAR

### 1. Abrir o Projeto
```bash
# Abrir diretamente no navegador
open index.html

# Ou usando servidor local
python -m http.server 8000
# Acesse: http://localhost:8000
```

### 2. Personalizar
- Cores: Editar `styles/colorsStyles.css`
- Tipografia: Editar `styles/fontsStyles.css`
- Conteúdo: Editar `index.html`
- Dados de projetos: Editar `js/projects.js`

### 3. Adicionar Imagens
- Colocar em `/img/`
- Atualizar caminhos em `index.html`

### 4. Deploy
- GitHub Pages, Netlify, Vercel
- (Veja GUIA_DESENVOLVIMENTO.md para detalhes)
