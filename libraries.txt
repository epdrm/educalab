BIBLIOTECAS UTILIZADAS - EducaLab
==================================

Este projeto foi desenvolvido utilizando HTML5, CSS3 e JavaScript vanilla, sem dependências externas de bibliotecas.

As únicas referências externas utilizadas são:

1. YouTube Embed API - https://www.youtube.com/embed/
   - Utilizada para incorporar vídeos do YouTube diretamente na página

2. Google Fonts (Poppins) - https://fonts.google.com/specimen/Poppins
   - Opcional: Para aprimorar a tipografia, pode ser adicionada via:
   - <link href="https://fonts.googleapis.com/css2?family=Poppins:wght@300;400;500;600;700;800&display=swap" rel="stylesheet">

TECNOLOGIAS UTILIZADAS:
- HTML5: Estrutura semântica da página
- CSS3: Estilização responsiva e animações
- JavaScript (Vanilla): Interatividade e controle dinâmico

RECURSOS JAVASCRIPT UTILIZADOS:
- DOM API (document.querySelector, addEventListener, etc.)
- Fetch API (caso seja necessário adicionar posteriormente)
- LocalStorage (caso seja necessário adicionar posteriormente)

ESTRUTURA DO PROJETO:
- /styles/: Arquivos CSS organizados por tema
  - colorsStyles.css: Variáveis de cores
  - fontsStyles.css: Variáveis de tipografia
  - mainStyles.css: Estilos gerais
  - heroStyles.css: Estilos da seção hero
  - carouselStyles.css: Estilos do carrossel
  - projectsStyles.css: Estilos dos projetos e modais
  - footerStyles.css: Estilos do footer

- /js/: Arquivos JavaScript organizados por funcionalidade
  - main.js: Funcionalidades principais
  - carousel.js: Controle do carrossel
  - projects.js: Filtros e modais

- /img/: Pasta para imagens do projeto
  - Substituir imagens de placeholder conforme necessário
