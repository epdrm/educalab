BIBLIOTECAS UTILIZADAS - EducaLab
==================================

Nenhuma biblioteca externa é utilizada atualmente.

O projeto usa HTML, CSS e JavaScript nativos, além de APIs do navegador, como
DOM, Canvas 2D, IntersectionObserver e requestAnimationFrame. Esses recursos
fazem parte da plataforma e não são bibliotecas externas.

Ao adicionar uma biblioteca ao projeto, registre-a aqui no formato:
nome da biblioteca - link da documentação
